# Status LC Frontend

React + Vite frontend for the Status LC learning center platform.

## Run

From `F:\project\StatusLC\frontend`:

```bash
npm.cmd install
npm.cmd run dev
```

Open:

```text
http://127.0.0.1:5173/
```

The frontend proxies `/api` and `/admin` to the Django backend on `http://127.0.0.1:8000`.
